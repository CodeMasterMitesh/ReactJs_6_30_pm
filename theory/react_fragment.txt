A React Fragment is a built-in React component that allows you to group multiple child elements without adding extra nodes to the HTML DOM. [1] (https://react.dev/reference/react/Fragment), [2] (https://legacy.reactjs.org/docs/fragments.html)In React, a component's JSX expression must always return a single parent element. Normally, developers wrap adjacent elements in a <div>, but this can clutter the DOM tree, mess up CSS layout stylings (like Flexbox or Grid), and output invalid semantic HTML. Fragments solve this problem
